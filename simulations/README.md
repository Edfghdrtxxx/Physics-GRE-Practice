# Simulations

Standalone interactive visualizers. Each file is one page; this folder is the reference for new ones.

Copy `oscillator.html` and swap the physics. Keep:

- Site tokens from `../css/style.css` and `../css/fonts.css` (cream / coral; dark via `[data-theme="dark"]`)
- KaTeX for equations
- A live mechanical canvas, plots, and sliders
- No emojis

Serve from the repo root (`python3 -m http.server 8000`) and open [http://localhost:8000/simulations/oscillator.html](http://localhost:8000/simulations/oscillator.html).
