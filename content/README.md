# Content — generated question bank & book assets

Four **gitignored** folders live here (copyrighted book-derived content — never pushed
to the public repo; the rule is enforced in `.gitignore`):

- `bank/` — generated question/formula blobs:
  - `cpg-questions.js` → `PGRE.BOOK_QUESTIONS` (146 end-of-chapter problems, per topic,
    with worked solutions and per-choice distractor explanations)
  - `cpg-exams.js` → `PGRE.BOOK_EXAMS` (Sample Exams 1–3, 100 questions each — powers
    the mock-exam simulator's legacy mode)
  - `cpg-formulas.js` → `PGRE.BOOK_FORMULAS` (334 formula cards, strictly 1:1 with the
    book's numbered equations per its EQUATION INDEX)
  - `ets-exams.js` → `PGRE.ETS_EXAMS` (5 intact exams: ets2024, gr1777, gr0877, gr0177,
    gr9677) and `PGRE.ETS_DRILLS` (gr8677, gr9277), generated by
    `tools/build-ets-exams.js` from `content/ets-src/` and loaded by `index.html`
- `book-assets/` — the figure JPEGs referenced by bank questions.
- `ets-assets/` — ETS exam figure assets.
- `ets-src/` — ETS exam source for `tools/build-ets-exams.js`.

`js/bank.js` merges question pools at load (20 preview + CPG chapter problems + ETS
drills by default; CPG/ETS exams when `includeExam` is set). Formula cards merge via
`PGRE.formulaDeck()` in `js/store.js`, not `bank.js`. Missing bank globals no-op via
`(list || [])` in `bank.js`; there are no committed empty placeholders. The `cpg-*.js`
files are generated blobs whose generator lives outside this repo. The site code
contains no book content itself.

The **Library** page (`#/library`) drag-drop import still works for any additional
markdown you want rendered in topic portals (stored in IndexedDB, searchable via
`#/search`).
